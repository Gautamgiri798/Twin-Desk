# Agent Instructions

Read `README.md` and the relevant documents in `docs/` before coding.

- This project requires a real Windows virtual display for true extended-desktop mode.
- A streamed window or mirrored desktop is only a prototype, not a completed extension.
- Do not claim native display, input forwarding, encryption or pairing works until implemented and tested.
- Keep the UI, networking, protocol, capture, driver and input modules separate.
- Verify Windows APIs against official Microsoft documentation.
- Do not accept unauthenticated input commands.
- Never commit secrets, signing keys, certificates, screenshots, keystrokes or clipboard contents.
- Make small changes, run tests, and update docs.
- Mark unimplemented functionality as TODO/stub and surface it clearly in the UI.
- Ask before installing drivers, changing system settings, or running destructive commands.
